# 微光集 Glimmer

单文件、纯本地存储的人生大事记时间线应用。打开即用，无需注册登录。

**在线使用**: https://linling856.github.io/glimmer/

## 功能

- 📅 时间线展示，竖向 / 横向切换
- 🗓️ 事件日期精度可选「年 / 月 / 日」
- 🎨 7 套主题，多角色、多时间线管理
- ▶️ 播放模式：时间线逐条生长动效
- 🌐 中英双语界面切换
- 💾 数据导出 / 导入 JSON 备份
- 📱 支持手机浏览器与添加到主屏幕

## 数据说明

所有数据仅保存在你的设备上，不上传任何服务器。换设备时用「更多 ⋮ → 备份」导出 JSON，在新设备导入即可。

## 云同步版

需要多设备同步？使用 [glimmer-cloud](https://github.com/LinLing856/glimmer-cloud)。
